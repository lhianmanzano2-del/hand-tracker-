# MediaPipe Hand Tracker

A real-time hand tracking project using Python, MediaPipe, and OpenCV.

## Features

- Real-time hand tracking
- Hand landmark detection
- Finger counting from 0 to 5
- Hand bounding box
- FPS counter
- Supports up to two hands

## Requirements

- Python 3
- Webcam

## Installation

Install the required packages:

pip install -r requirements.txt
